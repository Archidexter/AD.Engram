# AD.Engram

Лаунчер для Cyberpunk 2077: ставит и настраивает мод ИИ-NPC **NightCityNet** со всем, что ему нужно (RED4ext, Cyber Engine Tweaks, redscript, Codeware, ArchiveXL, TweakXL, Boneware), облачную или локальную озвучку, голосовой ввод и русский перевод. Удаляет всё поставленное так же аккуратно, как ставит.

## Установка

1. Скачайте `AD.Engram.zip` из раздела **[Releases](https://github.com/Archidexter/AD.Engram/releases/latest)**.
2. ПКМ по архиву → **Свойства** → внизу поставьте галочку **«Разблокировать»** → **ОК** *(Windows помечает скачанные файлы — это убирает лишние предупреждения системы)*.
3. Распакуйте в любую папку и запустите **`AD.Engram.exe`**.
4. Дальше — по подсказкам внутри лаунчера. Архив самого NightCityNet автор мода выкладывает в Discord: лаунчер откроет нужное сообщение и подхватит скачанный файл. Лаунчер обновляется сам.

## Игра

Cyberpunk 2077 из Steam, GOG или Epic. Проверено на версии **2.31**; с другой версией 2.x установка идёт с предупреждением. Игра без менеджера модов получает свою портативную копию Mod Organizer 2; с вашими Mod Organizer 2 или Vortex лаунчер работает напрямую.
